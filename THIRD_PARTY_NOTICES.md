# Third-party materials

World Domination II and its original game content belong to their respective
rights holders. This unofficial reconstruction is not endorsed by them.

The following materials derive from the original game and are not claimed as
newly authored project code:

- Game graphics, city images, vector artwork, audio and font data under `assets/`.
- Converted timeline, symbol, text-layout and linkage metadata under `assets/runtime/`.
- Python translations of original game classes and timeline scripts under
  `wd2/generated/`.

The existing Apache-2.0 LICENSE describes the repository's newly authored code
where its authors have authority to license it. It does not relicense original
game content, artwork, music, font designs or translated third-party material.
Redistribution permission for those materials has not been independently
established. Age, noncommercial use and a publisher's current status do not by
themselves remove copyright restrictions. Review applicable permissions before
redistributing or using the third-party materials in another project.

The source SWF and raw development exports are not distributed. Runtime assets
are individual files or converted declarative metadata, loaded by the Python
presentation adapters. Original font names and sound linkage names are retained
to reproduce the game interface; no ownership of those names is asserted.

Runtime dependencies Pygame CE, Pillow and resvg-py are installed separately
through pip and retain their own licenses.
